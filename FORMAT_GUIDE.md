# **The ZipIt.app format guide!**

### **Quick guide for format use case:**

1. *Large files for transfer ease use .gzip*
2. *Multiple files/folders into single file use .zip*
3. *Email attachments and internet downloads use .zip*
4. *Unix/Linux systems and software distribution use .tar*
5. *Large data transfer over internet use .tar*
6. *Split large files into smaller chunks use .rar*
7. *Windows-based archiving use .rar*
8. *Maximum compression for storage/transfer use .7z*
9. *Single file compression use .gzip*
10. *Cross-platform compatibility use .zip or .gzip* 

## **ZIP/.zip files**
 - *ZIP* files are compressed files that can be used to store multiple files or folders into a single file. They are often used to reduce the size of a large number of files or to make it easier to send them via email or download them from the internet.

 ## **Tar/.tar files**
 - *Tar* files (short for 'tape archive') are a type of file that combines multiple files into a single, compressed archive file. They are commonly used in Unix and Linux systems, but can also be used on other operating systems such as Windows. Tar files use the .tar file extension and are created using the tar command in the terminal. They are often used to distribute software or transfer large amounts of data over the internet.

 ## **RAR/.rar files**
 - *RAR* is a file format for data compression and archiving. It was developed by Russian software engineer Eugene Roshal and is mainly used on Windows-based computers. RAR files are similar to ZIP files, but RAR files can be split into multiple volumes, allowing you to save large files in smaller chunks and make them easier to share. To open RAR files, you will need a program that can extract the compressed data. There are several free and paid options available, such as WinRAR, 7-Zip, and WinZip.

 ## *T7z/.t7z files*
 - *T7z* files are compressed archive files that use the 7-Zip compression algorithm. They are used to store and compress multiple files and folders into a single, smaller file for easier storage and transfer.

 ## **Gzip/.gzip files**
 - *Gzip* Gzip files are compressed files that use the Gzip compression algorithm. They typically have a .gz file extension and are smaller in size than the original file. They are often used to compress large files to make them easier to transfer or store. They can be decompressed using a variety of tools, including the gzip command line utility or various compression software.
